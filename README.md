# Moonlight OS

Moonlight OS is a Debian live-build project. This repository contains the configuration files, hooks, and package lists used to build a custom Debian live environment using `live-build`. It is designed for use with Ventoy persistence partitions.

## Requirements

- **Debian-based system** (live-build is only available on Debian and Debian-derived distributions)
- live-build
- Related build tools
